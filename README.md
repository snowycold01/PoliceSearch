# PoliceSearch

**Commands**
------------------------------------
/search - Use this command while looking at a vehicle, if successful, you will open the vehicle's inventory, whenever this command is executed, along with whatever is taken or added is sent in a discord log after the player has closed the inventory page.

**Config**
------------------------------------
&lt;VehicleSearchDistance&gt; - This is how close the player has to be to a vehicle in order to use the command

&lt;BarricadeSearchDistance&gt; - This is how close the player has to be to a barricade in order to use the command

&lt;AlertPlayerAboutSearches&gt; - If enabled, a message will be sent to the player in-game if their vehicle is being searched

&lt;PolicePermission&gt; - This should be the Id of the permission group that can use this command

&lt;VehicleDiscordWebhook&gt; - This is where the log messages relating to vehicle searches will be sent

&lt;BarricadeDiscordWebhook&gt; - This is where the log messages relating to barricade searches will be sent
